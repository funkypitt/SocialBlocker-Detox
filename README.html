Social Blocker

Local DNS VPN that blocks YouTube, Instagram and TikTok on a schedule.

Overview

Social Blocker is a parental-control app that uses Android's VpnService to install a local, DNS-intercepting VPN. Only DNS traffic (UDP port 53) is routed through a virtual TUN interface; all other traffic flows normally — there is no upstream proxy, no certificate, and the device's regular network is not affected. DNS queries for the platforms you select (YouTube, Instagram, TikTok) are blocked at the device level, with optional daily schedule windows.

A password gate (PasswordActivity) protects the settings. The blocker auto-starts on boot and runs as a foreground "special use" service so Android does not kill it.

Features

  • Per-platform toggles: YouTube, Instagram, TikTok
  • Local DNS-only VPN — no upstream proxy or certificate
  • Schedule windows (e.g. 6-8,18-22) — outside those hours, blocking is on
  • Password-protected settings
  • Auto-start on boot, runs as a foreground special-use service
  • Always-on VPN supported (Settings → Network → VPN)
  • UI in French (res/values/strings.xml)

Build & install

Standard Android Gradle project.

./gradlew assembleRelease
# or
./gradlew bundleRelease

Application id: com.parentcontrol.socialblocker. Min SDK 24, target SDK 34. Required permissions include BIND_VPN_SERVICE, FOREGROUND_SERVICE and FOREGROUND_SERVICE_SPECIAL_USE, RECEIVE_BOOT_COMPLETED, POST_NOTIFICATIONS and REQUEST_IGNORE_BATTERY_OPTIMIZATIONS.
